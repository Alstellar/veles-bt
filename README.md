# Veles Helper

**Veles Helper** - расширение для Google Chrome, которое автоматизирует массовый перебор параметров и запуск бэктестов в Veles.

Текущая версия: **1.4.0**

## О проекте

Veles Helper помогает превращать ручной подбор параметров в системный процесс:
- вы задаете диапазоны значений;
- расширение генерирует комбинации;
- запускает тесты по очереди;
- сохраняет результаты и прогресс;
- позволяет остановить и продолжить задачу с того же места.

## Основные возможности

- Автоматический Grid Search по параметрам стратегии.
- Обновленный конфигуратор с расширенной валидацией и подсветкой проблемных разделов.
- Импорт настроек из ссылки на бота Veles формата `https://veles.finance/share/*****`.
- История запусков со статусами `RUN` / `STOP` / `DONE`.
- Остановка и возобновление задач тестирования.
- Защита от параллельных запусков (одновременно выполняется только одна задача).
- Адаптивная работа с несколькими вкладками Veles.
- Сохранение шаблонов конфигураций.
- Локальное хранение истории и результатов тестов.
- Страница настроек и выгрузка bug-report.

## Безопасность

- Расширение не требует API-ключей.
- Работа идет в рамках вашей авторизованной сессии Veles в браузере.
- Данные истории и шаблонов хранятся локально.

## Ограничения и поведение

- Поддерживается десктопный Google Chrome.
- Для работы нужно быть авторизованным на `veles.finance`.
- Veles ограничивает частоту запусков. Расширение автоматически делает паузы между тестами.
- Одновременно выполняется только один активный запуск.
- Задачи в статусе `STOP` можно продолжать из раздела "История запусков".

## Установка (разработка)

1. Клонируйте репозиторий.
2. Установите зависимости:
   `npm install`
3. Соберите проект:
   `npm run build`
4. Откройте `chrome://extensions`.
5. Включите `Режим разработчика`.
6. Нажмите `Загрузить распакованное расширение`.
7. Выберите папку `dist`.

## Команды

- `npm run dev` - режим разработки.
- `npm run build` - production-сборка.
- `npm run watch` - сборка в режиме наблюдения.
- `npm run lint` - проверка ESLint.
- `npm run check:encoding` - проверка кодировки текстовых файлов.
- `npm run fix:encoding` - авто-исправление BOM в текстовых файлах.

## Структура проекта

- `src/components/views` - страницы интерфейса (Главная, Конфигуратор, Шаблоны, История, Настройки).
- `src/services` - сервисный слой (API, очередь, валидация, импорт, хранение, синхронизация).
- `src/hooks` - бизнес-логика в хуках.
- `public` - `manifest` и статические ресурсы расширения.

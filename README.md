# 🚀 Veles Helper

**Ваш умный помощник для автоматизации и поиска идеальных настроек на платформе Veles Finance.**

![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)
![Status](https://img.shields.io/badge/status-Stable-green.svg)

> **Veles Helper** — это расширение для Google Chrome, которое превращает рутинный процесс создания бектестов в мощную систему **Grid Search**. Задавайте диапазоны параметров (например, перекрытие от 10% до 20% с шагом 5%), и помощник автоматически сгенерирует, запустит и сохранит сотни тестов, чтобы вы могли найти самую прибыльную стратегию.

---

## 📥 Как установить

Расширение доступно в официальном магазине Google Chrome. Установка занимает меньше минуты:

1.  Перейдите на страницу расширения: **[Скачать Veles Helper в Chrome Web Store](ССЫЛКА_НА_CHROME_WEB_STORE)** *(ссылка появится после публикации)*.
2.  Нажмите кнопку **"Установить"**.
3.  Откройте [Veles Finance](https://veles.finance), авторизуйтесь и запустите расширение через меню браузера.

---

## ✨ Основные возможности

### 🤖 Массовая генерация тестов (Grid Search)
Больше не нужно запускать тесты по одному вручную.
* **Умный ввод:** Вводите несколько значений для одного параметра (например, Мартингейл: `5%, 10%, 15%`).
* **Автоматические комбинации:** Расширение само переберет все возможные сочетания ваших настроек.
* **Очередь задач:** Veles Helper выстроит все тесты в очередь и выполнит их один за другим, пока вы занимаетесь своими делами.

### 🎛 Гибкая настройка стратегий
Поддержка всех ключевых параметров платформы Veles:
* **Базовые:** Выбор биржи, пары, депозита, плеча и направления (Long/Short).
* **Сетка ордеров:** Настройка количества ордеров, отступа, перекрытия и логарифмического распределения.
* **Smart Presets:** Быстрые шаблоны для заполнения полей (шаги 0.1, 1, 5 и т.д.).

### 📊 История и Шаблоны
* **Сохранение результатов:** Все пройденные тесты сохраняются в удобную таблицу с возможностью сортировки по профиту (Net Profit), количеству сделок и другим метрикам.
* **Шаблоны конфигураций:** Сохраняйте удачные наборы настроек, чтобы использовать их в будущем одним кликом.
